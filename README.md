# Chatterbox

A silly Dalamud plugin for creating configurable triggers and automated reactions to chat, emotes, and other in-game events.

## Features

- Create custom text and emote triggers
- React with messages, commands, or emotes
- Regex support for text triggers
- Filter by player, target, relationships, and other conditions
- Configurable cooldowns and reaction restrictions
- Import and export triggers

## Usage

Open Chatterbox with:

`/chatterbox`

Create a trigger, configure what should activate it and what Chatterbox should do in response.
